# EchoLens v0.1 发布范围（冻结）

确认日期：2026-10-11。状态：发布准备，尚未发布。用户授权先完成范围冻结、代码与UI整理；模型分发、完整发布材料、干净环境验收和正式上传为后续批次。

## 定位与边界

面向中文餐饮评价的本地意见挖掘工作台：导入反馈，提取对象、方面、情感、意图和原文证据，发现主题，人工复核并导出报告。数据来自ASAP公开餐饮评价及用户自行导入；不是大众点评官方产品，不宣称覆盖所有餐饮品牌或场景。

用户已取消当前跨行业扩展路线。原阶段4的游戏等新领域计划暂缓；本轮进入阶段5开源整理。企业定制仅是未来可能方向，不创建客户代码、数据、品牌页面或私有产品，后续另议proposal。

## 冻结能力

| 纳入v0.1 | 说明 |
| --- | --- |
| CSV/JSONL导入、去重、来源版本 | 保留原文和稳定ID；不可变分析快照 |
| 中文餐饮意见抽取 | 固定Qwen3.5-4B＋checkpoint102 QLoRA；28个方面ID（含unknown） |
| 意见统计、主题和原文证据 | 统计区分模型版本；不混用旧分类器与微调结果 |
| 人工复核和报告导出 | 机器结果不覆盖，审核追加历史 |
| 失败处理与续跑 | 超长、截断、字段或引用错误转复核，失败不作可靠证据 |
| 研究工具 | 原试标和独立对照工具单独进入，保留历史 |

不纳入：跨行业标签、企业专属功能、多租户/权限系统、云部署、全平台爬虫、新一轮训练、趋势/问答新功能。v0.1不提供时间趋势，即使导入含时间字段也不伪造已实现的趋势功能。

## 冻结模型与结果

- 模型和运行配置以`configs/stage3-candidate.json`为准；固定revision、checkpoint102、贪心生成、关闭思考、输入/输出各4,096 tokens。此次不修改该配置、推理worker或其哈希锁定的源码。
- 提示与标签公开副本放在`configs/prompts/restaurant-v0.1.txt`和`configs/labels/restaurant-v0.1.json`，逐字节匹配原冻结文件。启动器仅在本地兼容路径缺失时恢复它们，已有不同内容拒绝覆盖。
- 810训练/90开发均为AI标注；独立50条整体获用户认可，不等于50份完整金标准。字段合法48/50，未达到原99%目标。
- 当前已有1,000条工作台结果属于阶段2基线，不更名成微调成绩。已完成3条QLoRA工程探针不是新的质量评测。

## 本批交付与验收

1. 运行、训练、历史工具入口清楚；保留旧路径，避免移动后破坏复现材料。
2. 普通导航为数据导入、分析概览、主题与证据、人工复核、报告导出；研究工具及历史/工程数据独立入口。
3. 无本地数据时可进入导入页；缺少模型时能浏览既有结果，并解释不能启动分析的原因。
4. 统一启动器和后台解释器选择，不再把Windows路径直接写在调度逻辑中；不承诺本轮已验证Linux/GPU环境。
5. 旧审核、原文、推理结果和冻结模型哈希不变；新导航/空状态/缺资源/导出/复核测试通过。

本批不设置正式Git tag、不推送、不上传权重、不宣布发布完成。后续仍须完成权重安装与分发、模型卡、许可证与归因、轻量演示、依赖与干净环境验证。没有可获取的训练标注时，不能把训练脚本可运行宣传成训练结果可精确复现。
