# v0.1.0 安装与模型分发

源码：[xiaofei1412/EchoLens](https://github.com/xiaofei1412/EchoLens)。附件：[v0.1.0 Release](https://github.com/xiaofei1412/EchoLens/releases/tag/v0.1.0)。以下命令从项目根目录运行，仓库按源码方式使用，不是独立pip工具包。

## 只看UI / 导入数据

使用64位CPython；当前实际安装验证为Windows/Python3.14，其他Python版本和系统尚未验证。

```powershell
python -m venv .venv-ui
.\.venv-ui\Scripts\python.exe -m pip install -r requirements-ui.txt
$env:ECHOLENS_APP_PYTHON = (Resolve-Path .\.venv-ui\Scripts\python.exe).Path
.\.venv-ui\Scripts\python.exe scripts/start_workbench.py
```

浏览器打开`http://127.0.0.1:8501/`。可用`examples/feedback-import.jsonl`验证导入：原文选feedback、ID选id、评分可选stars、依据选自有或合成数据；2条有效、1条空文本排除。它是合成样例，不是模型成绩。缺资源时仅浏览/导入，不启动推理；历史研究包不存在时页面提示缺包，不下载真实评论。

## 完整GPU分析

推荐单独创建干净环境，不使用`--system-site-packages`。本机验收目标为RTX 5080 Laptop GPU 16GB、CUDA12.8版PyTorch；需要兼容的NVIDIA驱动。模型初次下载需要网络，分析使用本地文件。

```powershell
python -m venv .venv-release
.\.venv-release\Scripts\python.exe -m pip install torch==2.10.0+cu128 --index-url https://download.pytorch.org/whl/cu128
.\.venv-release\Scripts\python.exe -m pip install -r requirements-inference.txt
.\.venv-release\Scripts\python.exe -m pip check
.\.venv-release\Scripts\python.exe scripts/fetch_release_models.py
.\.venv-release\Scripts\python.exe scripts/model_bundle.py install --archive C:\path\to\echolens-v0.1.0-models.zip
.\.venv-release\Scripts\python.exe scripts/model_bundle.py verify
$env:ECHOLENS_APP_PYTHON = (Resolve-Path .\.venv-release\Scripts\python.exe).Path
$env:ECHOLENS_INFERENCE_PYTHON = $env:ECHOLENS_APP_PYTHON
.\.venv-release\Scripts\python.exe scripts/start_workbench.py
```

`C:\path\to\...`替换为Release下载的模型包完整路径。固定的上游revision在configs中，下载器同时取得生成模型、向量模型和编码器。自有模型包约475MB，底座另需数GB磁盘空间；实际压缩包字节和SHA256见本次发布准备报告。源码与对应模型清单必须属于同一候选版本。

安装器先验证整个包的成员、大小和SHA256，再写目标文件；原文件相同则跳过，不同则拒绝覆盖。它不删除旧结果、不自动修改冻结配置。安装目录沿用历史相对路径以兼容固定模型身份，用户不必手工创建那些目录。

在UI导入自己的授权餐饮评价，选择“餐饮微调模型”，进入概览后点击“开始 / 继续本地分析”。导入本身不会运行GPU。后台串行执行分类、QLoRA抽取、向量与主题；小于主题门槛时0主题正常。可从“主题与证据”查看意见，报告页导出；机器失败需复核，不能视为无问题。

## 发布者离线打包

```powershell
python scripts/model_bundle.py build --output artifacts/releases/echolens-v0.1.0-models.zip
python scripts/prepare_source_release.py --output artifacts/releases/echolens-v0.1.0-source.zip
```

打包为独占创建，已有同名包不会被覆盖。清单列出模型包的每个文件及哈希；仅打包adapter两文件、分类器、模型卡和许可。源码包排除data/models/artifacts、虚拟环境、凭据、缓存和权重。发布者输出在Git忽略目录中；不自动上传任何地方。

模型包作为独立Release附件分发，底座仍由上游下载。依赖完整快照`requirements-release-win-py314.lock.txt`描述本次Windows解析结果；安装主要入口仍是上面的分层requirements。验收范围和实测结果见阶段5开发记录。
