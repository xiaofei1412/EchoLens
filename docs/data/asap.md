# ASAP 数据卡（阶段 0）

来源：美团点评官方仓库 https://github.com/Meituan-Dianping/asap ，论文 *ASAP: A Chinese Review Dataset Towards Aspect Category Sentiment Analysis and Rating Prediction*（NAACL 2021）。固定 revision：`975122a60065240124df62cb4d5dbfd19ed9ef2c`。

上游仓库随附 Apache-2.0 LICENSE。本项目保留下载来源、原始 README、LICENSE、revision 和每个文件的 SHA256；数据许可证与项目代码许可分开。原始语料仅保存在被 Git 忽略的 data/。公开仓库提供下载脚本及统计，阶段 0 不重新发布原文副本。

## 实际字段与任务

- `id`：本数据集记录 ID，46,730 条记录中唯一；不能当商家、用户或时间 ID。
- `review`：原始中文评论。保留标点、表情、否定、错字、方言和转义字符串。
- `star`：1–5 星；原始 CSV 存在 `5.0` 这样的字符串，校验其为整数值后再规范化。
- 18 个方面字段：见 configs/labels/asap-v0.1.json。
- 方面标签：1=正面、0=中性、-1=负面、-2=未提及。未提及不是负面，也不是文件缺失值。

缺少真实时间、商家、用户、产品版本及原始网页 URL；没有意图、需求或证据跨度金标准。不能从 ID/文本顺序构造日期，也不能将此数据的星级当成某一方面的情感标签。

## 探索集

从训练集按 1–5 星各抽取 40 条，共 200 条，随机种子 20261007；排除与 dev/test 空白归一化后重复的记录。星级分层使负面样本更容易检查，不能用此样本估算真实星级占比。

原文及官方标签：data/exploration/asap-200.jsonl。AI 初读：data/exploration/asap-200-ai-notes.jsonl。AI 生成笔记用于发现标注边界，不作为人工金标准或测试成绩。

## 已发现的标注边界

对首批 25 条原文作了逐条 AI 检查，发现以下需要写入指南的情况：

- 同一篇对不同菜品褒贬不一；ASAP 文档级“口味中性”不能直接当每个意见单元中性。
- 排队等位、上菜慢、服务态度是不同维度；不能因为总体服务差就全部打负面。
- 便宜但不值：价格水平与性价比相反；数字本身不自动表示正负评价。
- 文本含其他店、上次体验或酒店住宿内容，需要按目标实体与场景区分。
- 反问、反讽、比喻、方言、错字和字面转义换行普遍存在。
- 存在单条评论内部大量重复句、疑似人员姓名与健康事件主张；保留本地原文，公开展示需要脱敏，不能将评论指控转述成已证实事实。
- 原有方面标签有可争议或遗漏之处；保留官方标签，另设复核意见，不静默覆盖。

数据陈旧和公开性意味着基础模型可能见过此语料；后续需要新领域、用途允许的独立金标准验证泛化能力。
