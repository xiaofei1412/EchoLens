# 阶段3独立样本核验

本轮准备50条未参与本项目训练、提示词修订或调参的评论，比较固定底座Qwen3.5-4B与已选定的QLoRA第102步。两版使用同一提示、标签、原文、NF4量化和greedy生成，关闭思考，输出上限4,096 tokens。你只需做成对质量判断，不必重新编写完整JSON。

2026-10-11：两版各50条已生成，ID/哈希/独立性复验通过。字段合法为微调前46/50、微调后48/50；输出上限分别2条、1条，均保留供审核。这是机械检查，不是语义准确率；人工审核尚未开始。[运行聚合报告](reports/stage3-independent50-inference.json)。

## 开始审核

打开工作台的[独立样本核验](http://127.0.0.1:8501/独立样本核验)页面。未运行时：

```powershell
.\.venv-stage1\Scripts\python.exe -m streamlit run app/streamlit_app.py --server.address 127.0.0.1 --server.port 8501
```

1. 侧栏选择“先看前10条”。这10条按抽样时固定顺序混排，含短文3、中等4、长文3；不是根据模型表现挑选。
2. 先读完整原文，自己找出主要意见；原文区域可滚动。再勾选“显示两版结果”。
3. 对照两版的对象、方面、情感、证据和归属。可切换原文高亮，选择具体意见编号定位；高亮只表示文字能匹配，不保证判断正确。
4. 分别勾选两版的问题，选择总体判断。必要时写“微调后#3的对象扩大了”“两版都漏了最后一句”等短备注；无需逐条修正JSON。
5. 勾选全文检查确认，点击“保存完成并下一条”。未看完可保存草稿；切换评论或关闭前需要保存。可分多次完成，侧栏可筛选未完成记录并导出全部审核历史。

前10条用于熟悉流程，完整核验分母仍为50条。不要只挑表现好的评论。若不确定含蓄或讽刺含义，选“暂无法判断”并写简短疑问，不必强行判对错。发现漏提时，备注引用缺失片段即可。

## 重点检查

| 问题 | 检查方式 |
| --- | --- |
| 漏提意见 | 从原文反查输出，尤其长文后半段、配料/子对象和中性事实；不要只核对已有高亮。 |
| 对象与范围 | 单道菜是否被扩大成整家店？同行、过去体验、假设条件是否被当成作者本次体验？ |
| 证据边界 | 是否缺少否定、条件或转折？是否把另一对象的正面子句包含在负面意见里？ |
| 方面、情感与意图 | 食材选择是否误当分量？规则说明是否无根据归为服务态度差？委婉表达、反讽是否误判？ |
| 重复与不当合并 | 同对象同方面同态度是否重复计数？不同对象或方面是否被强行合并？一句可以包含多条意见。 |
| 微调后的退步 | 不仅看新增加的正确意见，也看原先正确的意见是否丢失或变错；格式失败和截断也保留计入。 |

“微调后更好”是两版相对比较，不等于微调后全部正确。“两版接近且基本可用”和“两版接近但都有明显问题”分开记录；保存完成只是完成审核，不等于模型通过。格式/字段合法与原文定位检查也不代表语义正确。

## 独立性与结论边界

- 从ASAP官方test分区的4,896条合格候选中固定抽样：短文≤200字符15条，中等201—500字符20条，长文>500字符15条。未读取官方评分/方面标签，不根据两版预测选样。
- 排除所有官方train/dev（包含旧基线使用的被清洗排除记录）、历史探索/工作台/标注任务曝光记录，以及这些记录的去重组和规范化重复文本。固定810条训练、90条调参验证不与本包交叉。
- ASAP test曾用于阶段1已经冻结的分类模型评测，但未用于训练或调参；这里是本项目层面的独立核验，不保证基础模型预训练从未见过这些公开文本。现有去重仍可能漏掉语义近似评论。
- 本包只评估餐饮域，不能据此宣称跨领域泛化。长度分层刻意增加了长文覆盖，不等于ASAP总体长度分布。
- 本轮保存的是人工成对质量判断，不是逐意见的完整金标准；没有人工精确率/召回率/F1。未审核项不会自动记为通过，模型输出也不会升级为人工答案。
- 不用这50条选checkpoint、改提示/标签或加入训练。若审核发现共性问题，另找开发集案例进行修复；需要迭代后再次做独立质量结论时，另冻新样本，避免把已讨论样本继续当未见测试。
