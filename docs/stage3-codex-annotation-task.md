1. 阅读根目录 AGENTS.md 和本任务 `rules.md`。按顺序一次只打开一份 `inputs/batch-NNNN.json`，使用完整原文，不把900条一起读进上下文。长会话切换新对话时，重读规则并查询进度。
2. 逐条全文抽取，再核对 coverage；五条全部完成后保存为 UTF-8 JSON：`outputs/batch-NNNN.r1.json`。顶层严格为 `{"records": [...]}`，字段和枚举依 rules.md。内容直接写文件，聊天只报进度，勿打印整批JSON。可以分段编辑临时文件，完整后再改成约定文件名；不把未完成内容当成功结果。

4. 每批运行下方校验。失败只修当前批；修订已通过的文件时保留旧文件，另存 `.r2.json`，命令改 `--attempt 2`。同一批多个版本均保留，不自行合并成金标准。校验器不会自动补缺失字段。
5. 查看重叠提示、unknown标签和 review_questions。疑问必须如实保留，不为减少警告强行改标签。另存本轮简短 `outputs/RUN-NOTES-首次20条.md`（后续轮次换名），记录处理范围、界面模型/思考设置是否已知、版本、运行结果和具体疑问；不输出思维链。停止后由主开发对话进行语义抽查。

在工作区根目录执行（模型参数只是声明；实际界面不一致时如实修改）：
