A reviewable workflow

从反馈到报告，每一步都有依据。

01 / 输入与分析

保留原话，细分意见

按稳定ID导入和去重，提取对象、方面、情感、意图及归属。不同菜品与过去体验分开看。

02 / 主题与证据

聚合问题，也能回到原文

主题保留代表与边界片段。主主题至少涉及10条不同反馈，小众意见仍可查阅。

03 / 复核与导出

人来判断，修改留痕

失败输出进入复核。人工修订单独保存，不覆盖机器结果；导出带原文依据的Markdown报告。
